# 雷霆突击

一个零依赖的浏览器纵版飞行射击游戏。

## 运行

直接打开 `index.html`，或在目录中运行：

```bash
python3 -m http.server 8080
```

然后访问 <http://localhost:8080>。

## 操作

- `WASD` / 方向键：移动
- 空格：射击
- `P` / `Esc`：暂停
- 手机或平板：拖动战机，自动射击

## 一局怎么玩

开始后用移动避开敌机与弹幕，同时持续射击。初始有三条生命；普通波次随时间推进，每第四波会遇到首领。击败首领后进入下一波。拾取火力道具会提升散射火力，最高四级，界面上的火力标记会同步变化。

桌面需要按空格射击；触屏拖动战机时会自动射击。按 `P` 或 `Esc` 切换暂停与继续；生命耗尽后在结束画面重新开始。

### 高分保存在哪里

最高分在一局结束时写入当前浏览器的本地存储。换浏览器、设备或站点地址不会自动共享记录；清理站点数据也会清除它。保存的是最高分，不是可以接着玩的局内进度。

## 从源码学习纵版射击

页面入口是 [index.html](index.html)，绘制与玩法集中在 [game.js](game.js)。可按以下顺序阅读：

- `shoot`：火力等级如何改变弹道与射击间隔。
- `spawnEnemy` 和 `update`：敌机生成、波次推进、移动与碰撞。
- 游戏结束段落：分数比较和 `thunder-high-score` 本地记录写入。

这个浏览器游戏使用「雷霆突击」作为名称。想观察不同模型如何实现类似题材，可读 [雷电多模型对比](https://github.com/majiayu000/leidian) 的运行与评分说明。
